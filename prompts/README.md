# Role prompts

One person copies the **entire** role file P1..P5 into their independent Claude Code or Codex conversation, operating on their **own clone and feature branch**. Give every agent the repository's `AGENTS.md`, `CLAUDE.md`, `docs/IMPLEMENTATION_RUNBOOK.md` and `docs/contracts.md` context. These role prompts do not grant permission to push directly to main or modify unowned modules. Team lead reviews PRs.
